Servidor MCP

A única porta dos agentes para documentos e ferramentas. Decide o que cada agente pode chamar, confere tudo o que é gravado, calcula com fórmulas fixas, registra cada chamada e monta o relatório.

O caminho de uma chamada

Dois eixos de autorização independentes: o agente decide quais tools existem; o usuário, quais documentos. O token do agente tem de ser do mesmo usuário do JWT.

EixoCredencialDecide
AgenteAuthorization: JWT curto, assinado com MCP_AGENT_SECRET (agente, execução, usuário)quais tools existem
UsuárioX-User-Token: o JWT do indexador, repassado só a elequais documentos existem

Política por agente

agentes:
  extrator:
    tools: [listar_documentos, buscar_trechos, ler_chunk, ler_pagina,
            salvar_indicador, salvar_nao_encontrado, fechar_extracao, ler_extracao]
    limites:
      chamadas_por_execucao: 250
  • Aplicada no servidor: tools/list devolve só as tools do agente.
  • Agente fora do arquivo não tem acesso a nada. Criar um agente não concede permissão.
  • Relida quando muda, sem reiniciar; arquivo inválido mantém a última versão boa.
  • Cada tool que grava tem um dono só. O orquestrador não tem tool que leia trecho de documento.

Fechamento: cálculos e validações

fechar_extracao exige os 8 indicadores (valor ou não encontrado) e os valores de apoio para calcular o que a empresa não informa. Calculado nunca aparece como informado.

Texto do modelo

  • Marcadores: resumos e respostas usam {{doc_id.receita_liquida}}, que o código troca pelo valor guardado, com unidade e página. Número escrito direto só passa se estiver num trecho citado.
  • Citações: [[doc_id:chunk]] é conferido e vira “(arquivo, p. N)”. Na análise, a citação tem de existir literalmente no chunk.
  • Comparações (“qual a maior margem”) são feitas por comparar_indicadores, com os valores guardados. O modelo não compara números.
  • Ausência não é achado: item de análise que nega (“não traz guidance”) vai pela tool de ausência, com evidência.

Pendências e relatório

montar_relatorio gera o Markdown a partir da base: resumo por empresa, tabela comparativa, análise com citações, as perguntas com fontes, alertas e o que não foi encontrado com a evidência. Nenhum número é redigitado.
