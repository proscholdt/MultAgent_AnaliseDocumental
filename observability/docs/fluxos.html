Um trace, ponta a ponta

Sinais ligados entre si

  • Log → trace: a linha com trace_id= tem o link “Abrir o trace”.
  • Trace → logs: cada span mostra as linhas do Loki com o mesmo trace_id.
  • Métrica → trace: os exemplares do Prometheus apontam para traces reais daquele ponto do gráfico.
  • Mapa dos serviços: gerado pelo Tempo, com taxa e latência de cada ligação.

A sala dos agentes

Para acompanhar uma execução enquanto ela acontece, a sala dos agentes desenha os agentes trabalhando, a partir dos passos do orquestrador e da auditoria do servidor MCP, e tem uma aba com os logs do Loki. O Grafana fica para o que se mede no tempo: custo, tokens, latência, erros.

Como subir

cd observability && docker compose up -d     # Grafana em http://localhost:3001

Os serviços já apontam para o coletor (OTEL_EXPORTER_OTLP_ENDPOINT=http://alloy:4318). Vazio no .env de um serviço desliga a exportação dele; com a pilha fora do ar, os serviços seguem normalmente. O texto das mensagens dos modelos (prompts, respostas, resultado das tools) entra nos traces com traces_com_conteudo: true em agents/config/ajustes.yaml, ligado aqui: a chamada chat no trace mostra as mensagens, como no LangSmith.
